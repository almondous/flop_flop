Five races.One landing.

Five official fixes reached Technocore main on 19 October. Together they make the human-facing page obey the latest identity, the latest delegation read and the server's corrected room cursor—while repairing two exact data-contract bugs.

WHAT CHANGED

Old work can no longer overtake the new choice.

15:50:50 UTC · #942

The last sign-in wins

A slow passkey prompt, seed import or restored session can no longer replace a newer identity choice after it finishes. New choices invalidate old work, and ceremony timeouts release cleanly.

15:51:53 UTC · #939

Delegations stay with their owner

A late delegation read for identity A can no longer overwrite identity B's verified grants or surface A's error. Signing out also clears the old rows immediately.

15:51:19 UTC · #959

Empty pages still move the cursor

When the server corrects a future room cursor with no messages, the browser now accepts that checkpoint. A bad future permalink no longer hides every message posted afterward.

15:49:57 UTC · #728

19 digits remain 19 digits

Delegation ranking now uses BigInt instead of Number, preserving exact order above JavaScript's safe-integer ceiling and matching the Python signer.

15:19:29 UTC · #892

Create-only writes speak boolean

The WebMCP write_note tool now sends if_absent: true, not numeric 1. That aligns the payload with its schema and the server contract.
