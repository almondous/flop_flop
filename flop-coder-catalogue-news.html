A new identifier, with explicit limits.

The official gateway catalogue now includes qwen/qwen3-coder-30b-a3b-instruct-fp8. The last successful comparison snapshot on 14 November held two entries; the 15 November read was inconclusive, so this report does not date the addition more precisely.

Its detail record advertises text input and output, a 4,096-token context and a 512-token completion ceiling. Supported parameters are max_tokens, temperature and top_p. The description says tool turns are not yet offered.

The fields are different kinds of evidence.

At finalized Devnet block 3,838,409, the registry contained the same published model name and hash, marked Verified, with two mirror entries. That corroborates registered identity; it is not an independent test of the weights, serving quality or a completed job.

Precision labels kept separate

The detail record declares fp8 for quantization and weight precision. It separately reports BF16 as registry precision. We preserve both labels rather than treating a model name as a measured serving-format certificate.

A listing is the start of an inspection.

The new entry has one advertised price source labelled devnet-nominal. The API’s capacity value is derived from admission data, while measured throughput and latency are absent. Neither field establishes practical performance.

Free estimate requests timed out during this check. This report verifies the catalogue addition and its registered identity; it does not establish a quoted charge, working generation, code quality or finalized settlement.
