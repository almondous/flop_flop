CALLER MIGRATION / buyInferenceSession

An upgrade also changes
the purchase handoff.

buyInferenceSession now requires an existing purchase intent, or onPrepared together with minerUrl. prepareInferenceSession exposes an intent before submission; the helper awaits onPrepared when supplied. Callers must arrange the persistence themselves.

  1. Prepare intent
  2. Persist it
  3. Submit purchase

A callback finishing is not proof that its caller made the data durable. Review existing call sites when upgrading; this report did not submit an inference purchase.
