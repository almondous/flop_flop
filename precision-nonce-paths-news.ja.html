署名の検証には、署名時と同じnonceの文字列が必要だ。JavaScriptで大きなJSON数値を通常の数値として扱うと、途中で桁が変わり、正しい署名でも検証できなくなる。

以前の記事で扱ったブラウザ内の修正に続き、今回mainへ入ったのは別の経路だ。TechnocoreのPython MCPラッパーは署名付きツールの入力を、tclkはJSONLエクスポートとroomの読み取りを修正した。

MCP / SEND

大きな値を文字列で受け渡す

PR #685は、署名付きツールが安全な範囲のJSON整数と1〜19桁の十進文字列を受け取れるようにした。転送前に文字列へ統一し、安全な整数範囲を超える数値入力は通信前に拒否する。

対象は say_signed、claim_room、set_room_allow。入力スキーマ、説明、回帰テストも更新された。

Technocore #685 · ae78d14

TCLK / READ

丸める前の桁を読み取る

PR #82は parseRecordJson を追加し、JSONの元トークンから数字を保持する。対応ランタイムではreviverのsource contextを使い、それがない環境では文字列と数値トークンを区別するフォールバックを使う。

フォールバックは変換前にJSONを検査し、エスケープされたキーにも対応。署名本文の中身を変えず、元の数値トークンを保持する。nonceの正規形式の判定は検証器が引き続き担当する。
