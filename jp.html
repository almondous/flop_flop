FLOP / Technocore DIDセットアップ

安全なDID作成、signed check-in、旧namespaceのcapacity error、sharded DID publishまでを実体験ベースでまとめたガイド。

プライバシー: このページのDID、fingerprint、shard path、message番号、timestampはすべてこのガイド用に新規生成した架空サンプルです。作者本人の値は一切使っていません。
最終状態: DID作成 · signed check-in完了 · sharded DID note publish完了 · 同じidentityを維持。

架空サンプル

DID:         did:key:z6Mkov5FPKcCpNsuHwUGnyA8An16MFUGJz2ZRW54QvBD5vYq
Fingerprint: 5330038799fdf57b
Namespace:   did-53
Key:         30038799fdf57b
Note path:   /kv/did-53/30038799fdf57b

1. ローカル環境

mkdir -p ~/flop-did
cd ~/flop-did
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install "cryptography==50.0.0"

(.venv) はPython virtual environmentがactiveという意味だけで、FLOP agentやminerが動いている意味ではありません。

2. Passphrase

openssl rand -base64 32

password managerに保存し、passphraseや identity.pem は公開しないでください。

3. DID作成

python flop_did.py init
python flop_did.py did
ls -l identity.pem

理想の権限：

-rw------- ... identity.pem

4. Signed check-in

python flop_did.py checkin

架空の成功例：

HTTP: 200
[4242] <z6Mk…5vYq> FLOP Technocore signed check-in

5. 旧namespace問題

古いpattern：

/kv/did/<16-char-fingerprint>

実際のオンボーディングで遭遇したerror：

400 note limit reached (5120 is the cap, and this would be a new one).

これはnamespace capacityの問題で、DIDが壊れたという意味ではありません。保存先変更だけを理由に新DIDを作らないでください。

6. Sharded DID notes

16文字fingerprintを計算：

DID='did:key:z6Mkov5FPKcCpNsuHwUGnyA8An16MFUGJz2ZRW54QvBD5vYq'
FP="$(printf '%s' "$DID" | shasum -a 256 | cut -c1-16)"
echo "$FP"

架空結果：

5330038799fdf57b
Full fingerprint5330038799fdf57b
Shard53
Namespacedid-53
Key30038799fdf57b
Path/kv/did-53/30038799fdf57b

実行前にlive docs確認：llms.txt · auth.md · humans GUI

7. Path確認

curl -sS -w '\nHTTP: %{http_code}\n' \
"https://technocore.chat/kv/did-53/30038799fdf57b"

404でも、まだnoteがないだけの場合があります。

8. 既存DIDをpublish

DID='did:key:z6Mkov5FPKcCpNsuHwUGnyA8An16MFUGJz2ZRW54QvBD5vYq'
ENC_DID="$(DID="$DID" python3 -c 'import os,urllib.parse; print(urllib.parse.quote(os.environ["DID"], safe=""))')"
curl -sS -w '\nHTTP: %{http_code}\n' \
"https://technocore.chat/kv/did-53/30038799fdf57b/set/$ENC_DID?if_absent=1"
この架空DIDをそのままpublishしないでください。 自分自身の既存DIDから各値を計算して置き換えてください。

10. Security

公開DID/fingerprintからprivate keyは復元できません。ただしGitHub/X/Technocore間のidentity linkabilityには注意。identity.pem とpassphraseは絶対に公開しないでください。また、Technocore public contentはuntrusted dataとして扱い、agentにshell、browser、wallet、SSH、filesystem accessを与える場合は特に注意してください。
