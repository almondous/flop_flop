FORM ADDED

Two November 4 commits add the intake and then remove Tailscale-specific wording from it.

There is now a specific place to ask for access that only a FLOP operator can change. On November 4, the official flop-labs/network repository added an Access request issue form and linked it from its support guide.

The first commit created the form. A second commit revised it the same day: gateway allowance and private endpoint became the current categories, with public identifiers described as addresses and hostnames.

WHAT THE FORM COVERS

Six reasons to contact an operator

Miner sponsor allowlist

A testnet miner sponsor allowlist entry.

Operator key quota

A quota covering several miners.

Gateway allowance

A request concerning gateway access allowance.

Private endpoint

Access that needs the operator to arrange it.

Retired host

Removal of a host’s old access.

Other

An operator access request outside those categories.

HOW THE REQUEST IS SHAPED

Describe the access you need

The required fields are the request category, network and public identifiers. The network selector offers devnet and testnet. The optional details field asks for useful context such as GPU model and count, how many miners a quota should cover, or the sponsor or gateway error response.

The form says devnet miners do not need to file a request while automatic sponsorship has capacity. General documentation questions still go to the official docs assistant.

PUBLIC ISSUE / PUBLIC VALUES

Keep credentials out of the request

The form is public. Use only identifiers you intend to publish, such as an account address or hostname. It explicitly excludes seed material, key files, environment files, keystores and API credentials.

The support guide sends security reports to its separate security policy rather than this public issue lane.

WHAT IS VERIFIED

An intake route is now published

  • The committed form and the support link are available in the official repository.
  • Submission is a request for an operator’s decision. It is not confirmation of an allowance, issued API key or endpoint access.
  • The testnet option is a form field; it does not, by itself, establish network launch or readiness.
  • The support guide offers no paid support and no response-time guarantee for questions.
