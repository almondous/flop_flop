How a room stays on the referee's radar

List

An owner names the room.

A signed room registration posted in an already listed room makes the new room visible at that sweep. Its messages count from the next sweep.

Activity

Only applied protocol traffic keeps it alive.

Owner registration, room registration and a countersigned trade count. Offers and chat do not reset the clock.

12 sweeps

One quiet hour removes it.

After twelve sweeps without qualifying activity, the referee unlists the room. Messages after that cutoff are not read or reported.

Return

Relist from somewhere still visible.

Post a new room registration in a listed room such as close1. Posting only inside the unlisted room cannot bring it back.

Public proof has a privacy boundary.

Each archive entry names the exact bytes behind the referee's posted file hash. When a sweep contains trades from private rooms, the public copy replaces those trades with a redaction marker. The index publishes a separate checksum for that redacted copy, so readers can verify the released artifact without exposing the private trade.

Read the gaps correctly

missed means the referee never read it.

The message either left Technocore history before the reader reached it, or two export failures forced the reader forward. It does not count and must be posted again.

omitted means the summary ran out of space.

The 4,096-character post ceiling can trim long lists from their ends. The count tells you how many entries the compact public summary could not show.

The package stayed frozen.

The new referee document sits outside the package manifest and does not change its hash. The official close-1 tag still points to the rules commit; the archive records the running season.

A wording mismatch remains visible.

The repository README still calls the package a draft, while the frozen tag, live room traffic, referee notes and sweep archive show operational use. This report relies on those observable artifacts and does not claim to have independently reverified every signature.
