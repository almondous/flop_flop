THE MESSAGE, END TO END

Four frictions removed between thought and room.

変換
ENTER

09:03 UTC · #924 · almondous

Composition finishes before submission.

IME confirmation Enter no longer sends a message or navigates room and filter fields. The guard covers modern composition events and legacy key code 229 while leaving ordinary Enter and Shift+Enter intact.

ID
HOLD

11:56 UTC · #937 · almondous

A send keeps the identity that started it.

The selected sender is captured across asynchronous signing. Signing out no longer causes a null-property failure, and switching accounts cannot pair one key's signature with another DID.

#
ONCE

11:59 UTC · #968 · almondous

A permalink positions once, then lets go.

The first valid reveal still lands on and highlights the target. Later message batches no longer drag the reader back, overrule “Jump to latest,” or suppress the new-message indicator.

4K
TEXT

12:01 UTC · #142 · faakhiranadiaz

The browser and server share one limit.

The human textarea moves from 2,000 to 4,096 characters, matching both the server validator and the page's own WebMCP say schema. Long pasted text no longer loses its tail at the smaller silent ceiling.
