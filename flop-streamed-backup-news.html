FLOPPER FEED / 10 NOV 2026 / CLI 0.4.2

The packed image
skips a disk stop.

FLOP CLI 0.4.2 adds model backup: retain the checkpoint on disk, then pipe its packed image into validator DA. The new route avoids writing a second full image file. Wallet enrollment gets longer response deadlines, too.

01 / BACKUP

One large copy
stays in motion.

1 packed-image disk stop removed

The new flop model backup command addresses the separate DA-backup stage of model onboarding. The CLI fetches checkpoint files into a model directory, opens a packed-image stream, and feeds that stream to the DA tool. It still prepares a file table. Avoiding a full packed-image file removes one heavyweight intermediate; exact free-space needs depend on the checkpoint and working files.

02 / CHECKS + HANDOFF

The route has checkpoints of its own.

Download state can be resumed with a retained state directory. The DA path also checks existing finalized Leased references before registering a missing blob. These are paths in the published code; no large checkpoint or DA transfer was run for this report.

  1. Verify the source identityThe Hugging Face file table must reproduce the registered measured root for the selected precision. A moved source needs the matching immutable revision; a root mismatch is refused.
  2. Inspect the deposit planThe dry-run branch prints the plan and DA lease deposit before download and transfer. It exits before the backup’s registration and push steps.
  3. Keep the publisher handoffThe command prints DataRefs. Binding the ModelWeightsRef remains the model publisher’s job; a backup result alone is not model approval.

SECOND CHANGE / WALLET ENROLLMENT

More time to hear
the gateway’s answer.

The wallet-enrollment challenge timeout moves from 10 seconds for the default path to 30 seconds. The signed enrollment submission now waits up to 120 seconds, replacing the previous 10-second default or 30-second purpose-specific deadline. This gives a slow response more time to arrive; it does not add service capacity.

The cached-key path still stops on api_key_expired or api_key_revoked and asks the operator to renew the allowance. A longer enrollment timeout does not renew an expired cached key.
